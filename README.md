# MedKey 0.2.0 — 日本語かな＋医療用語

iPhone用の独立した日本語キーボードです。無料で使えるAzooKeyKanaKanjiConverter v0.11.2と既存の医学辞書を組み合わせます。Apple標準の変換エンジンではなく、変換精度が同じであることを保証するものではありません。

## 変更点

- 「あ・か・さ／た・な・は／ま・や・ら」の日本語かな配列。下段は小書き・濁点、わ、句読点。
- 左に英字・数字・地球儀、右に削除・空白・確定／改行・カーソル移動。
- フリック中に方向別の文字を表示。削除の長押しに対応。
- 一般語、文章、読み途中の予測候補と医学用語を併記。普通の言葉の候補が医学用語だけで埋まらない並びにしました。
- 候補の一覧表示と、直前の確定を読みへ戻す操作。
- 一般語の候補選択を端末内で学習。ネットワーク通信やフルアクセスは不要です。
- 医学辞書の基本78,956件をキーボードで検索します。追加の実践用語79,845件は、原典に一般語・誤記も含むため本体アプリの試し検索で任意に検索できます。

## iPhoneでの更新

GitHub Actionsの最新の成功した実行から「MedKey-unsigned-IPA」をダウンロードし、ZIPを展開します。WindowsのAltServerでSideload .ipaから新しいIPAを選び、同じApple Accountで更新してください。キーボード拡張は保持します。

設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → MedKey Keyboard。メモで地球儀から切り替えます。フルアクセスは不要です。

無料署名には有効期限があります。パスワード入力欄や独自キーボードを禁止するアプリではApple標準キーボードへ切り替わります。

## 開発・確認

XcodeGenでproject.ymlからプロジェクトを生成します。Swift 6.1対応のXcodeが必要です。GitHub Actionsで依存パッケージを取得し、ライセンス・帰属文をResources/ThirdPartyNotices.txtへ収集します。シミュレータで一般語・文章・医学用語の変換、かな配列・キーの寸法を検査し、実機用ビルド後に未署名IPAを出力します。

WindowsではiOSアプリを実行できません。実機の入力感、アプリ間の動作、キーボード拡張のメモリ上限は、更新後にiPhoneでも確認が必要です。
