## 仕様
### 万病辞書のファイル構成
(1) __出現形__
電子カルテや退院サマリから抽出された症状・病名（全角）．
（例：１１β−水酸化酵素欠損症，１８常染色体異常等）

(2) __出現形よみ__
出現形のよみがな（全角）．
* 信頼度LEVELがSの病名：ICD10対応標準病名マスターに記載されている病名表記カナをもとに付与
* 上記以外の病名：「万病辞書 よみがなくん」により自動付与し，一部人手により修正．なお，読みの候補が複数存在する場合は，音読みを優先．（誤りがある場合もございますので，参考までにお使いください）

(3) __ICD10コード__
ICD10対応標準病名マスターに記載されているICD10コード．
下記に該当する症状・病名については-1を付与．
* 4つ以上のコードが存在する場合（3つまでは区切り文字には；（半角セミコロン）を用いて全て付与）
* 断片的な情報のみで判断が困難な場合
* コードが存在していない場合

(4) __標準病名__
ICD10対応標準病名マスターに記載されている標準病名（全角）．
なお，ICDコードに複数の標準病名が対応し，一意に決まらない場合は，それらの一部または全てを付与．複数存在する場合の区切り文字には；（半角セミコロン）を使用．また，ICD10コードが -1の場合には，標準病名にも -1を付与．

(5) __信頼度レベル__
標準病名およびICDコードのコーディングに対する信頼度を表す．
* _S_: ICD10対応標準病名マスターに記載されている症状・病名
* _A_: 2名以上の医療従事者が同じコードを付与した症状・病名
* _B_: 2名以上の医療従事者が相談してコードを付与した症状・病名
* _C_: 1名の医療従事者がコードを付与した症状・病名
* _D_: 計算機が自動的に割り当てた症状・病名
* _E_: 新規に追加された症状・病名のうち，万病辞書に収載済み病名のICD コードと標準病名を元に，計算機が自動的に割り当てた症状・病名
* _F_: 新規に追加された症状・病名のうち，万病辞書に収載済み病名のICD コードと標準病名を元に，計算機が自動的に割り当てられなかった症状・病名

(6) __頻度レベル__
本研究室で収集した医療文書における出現形の出現頻度を降順でソートしたときの順位を5％ごとに区切ったレベル（95-100%など20段階）を付与．出現頻度が0の場合には「出現なし」を付与．
